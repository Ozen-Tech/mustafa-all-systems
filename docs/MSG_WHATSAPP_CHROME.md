# Mensagem pronta — abrir o app no Chrome (Samsung)

Copie e cole no WhatsApp para promotores com problema de GPS/câmera:

---

Oi! Se o GPS ou a câmera não funcionar no app, é porque o celular abriu no *Internet Samsung*.

Faça assim:

1. Abra o *Chrome* (ícone redondo colorido)
2. Cole este link: https://promotor-mustafabucket.web.app
3. Quando pedir, toque em *Permitir* localização e câmera
4. (Opcional) Menu ⋮ → *Instalar app* ou *Adicionar à tela inicial*

Pronto — use sempre pelo Chrome ou pelo ícone na tela inicial.

---

No próprio app também aparece o botão **"Abrir no Chrome"** quando detectamos Internet Samsung.
